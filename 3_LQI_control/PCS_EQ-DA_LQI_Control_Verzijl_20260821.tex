\section*{Introduction}
This report presents the development of a \textit{Linear Quadratic Integral} (LQI) controller for the EQ-DA system. The controller is based on a state-space model identified from experimentally acquired closed- or open-loop data. Because the EQ-DA exhibits open-loop instability, system identification can be performed under \textit{Proportional-Integral-Derivative} (PID) stabilization using \textit{pseudo-random binary sequence} (PRBS) excitation, or by applying a open-loop PRBS signal around a (manually found) operating point.

The identified model is subsequently used to design a Kalman state observer and an LQI controller. The resulting control architecture combines optimal state-feedback control with integral action to achieve accurate setpoint tracking while eliminating steady-state error. Ideally, the LQI controller is tuned with a slider tool to adjust the trade-off between control effort and tracking performance. The report also includes experimental results demonstrating the effectiveness of the proposed control strategy.

The proposed methodology can be applied to both the inner and outer control loops of the EQ-DA system. The report describes the system identification procedure, observer design methodology, controller synthesis, and experimental results.

\section{Methods}
This section describes the proposed model-based control design procedure. As illustrated in Figure~\ref{fig:workflow}, the method consists of four sequential steps: Closed-loop data collection using PID stabilization and PRBS excitation, or open-loop data collection with PRBS excitation, state-space model identification using the \textit{numerical algorithms for subspace state space system identification} (N4SID) algorithm, Kalman observer design for state estimation, and \textit{Linear Quadratic Regulator} (LQR) and \textit{Linear Quadratic Integral} (LQI) controller synthesis based on the identified model. Each step is described in detail in the following sections.

\subsection{Control strategy}
Figure~\ref{fig:control_architecture} illustrates the proposed control architecture. The controller consists of three components: a Kalman state observer, state-feedback control, and integral action. The Kalman observer estimates the system states from the measured output and applied control input. These estimated states are fed back through the gain matrix $K$ to generate the control action. The state-feedback gain is computed using LQR theory, which minimizes a cost function that balances state regulation and control effort. To eliminate steady-state tracking errors, an integrator is added around the output error. The resulting augmented controller is referred to as a LQI controller. By including the integral state in the control law, the system can accurately track reference signals while maintaining the advantages of optimal state-feedback control.

\subsection{State-space model}
A key step in model-based control design is the development of a state-space representation of the EQ-DA dynamics, this can also be called the mathematical model. The state-space model provides a compact mathematical description of the system in terms of internal states, control inputs, and measured outputs.
\begin{equation}
\begin{aligned}
x[k+1] &= Ax[k] + Bu[k] \\
y[k] &= Cx[k] + Du[k]
\end{aligned}
\end{equation}
where:
\begin{itemize}
    \item $k$ is the discrete time index,
    \item $x[k] \in \mathbb{R}^{n}$ is the state vector, the number of states depends on the order of the system,
    \item $u[k] \in \mathbb{R}^{m}$ is the control input, $m$ is the number of inputs of the system,
    \item $y[k] \in \mathbb{R}^{p}$ is the output, $p$ is the number of outputs of the system,
    \item $A \in \mathbb{R}^{n \times n}$, $B \in \mathbb{R}^{n \times m}$, $C \in \mathbb{R}^{p \times n}$, and $D \in \mathbb{R}^{p \times m}$ are the system matrices.
\end{itemize}
A dynamically complex system results in a higher order state-space model (higher $n$), while a simpler system results in a lower order state-space model (lower $n$). The state-space model can be used to design controllers, such as LQR and LQI controllers, to achieve desired performance and stability characteristics. \textit{Model predictive control} (MPC) can also be designed based on the state-space model, allowing for optimal control of the system over a finite time horizon.

\subsection{State-space model identification}
\subsubsection{Closed-loop identification}
As the EQ-DA is open-loop unstable, closed-loop identification can be used to obtain its state-space model. Figure \ref{fig:closedloop_identification} shows a roughly tuned PID controller to stabilize the system during identification, while a PRBS excites it across a range of frequencies. The PRBS is generated using the \texttt{prbs} function from the \texttt{python-control} package and applied as the reference input. The resulting input-output data is then used with the \texttt{n4sid} method to estimate the state-space matrices $A$, $B$, $C$, and $D$. Importantly, the PID controller output acts as the actual EQ-DA input and is therefore used as the input signal for the \texttt{n4sid} identification algorithm. The identified model can subsequently be used for controller design and analysis. However, this method requires a roughly tuned PID controller to stabilize the system during identification, which may not always be feasible or desirable. In such cases, open-loop identification can be performed around a manually found operating point.

\subsubsection{State interpretation} When a known mathemathical model is used wihtin system identification, one would know that the identified states correspond to physical quantities such as pressures, flows, or other relevant variables. However, in the case of the EQ-DA, no mathematical model is available, and the identified states are not directly interpretable. The states can be thought of as abstract representations of the system's internal behavior, which may correspond to physical quantities such as pressures, flows, or other relevant variables. This strategy is normally called a black-box model, where the focus is on capturing the input-output behavior of the system rather than explicitly modeling its internal dynamics.

\newpage
\subsection{Kalman observer}
After finding the state-space model, a state observer can be designed to estimate the system states from the measured output and applied control input. The observer provides an estimate of the internal states, which may not be directly measurable, allowing for feedback control based on these estimated states. The observer is particularly useful when some states are not directly measurable or when measurement noise is present.

Different types of state observers can be designed. In this report, a Kalman state observer is designed based on the identified state-space model. The Kalman filter is an optimal state estimator that minimizes the estimation error covariance by considering both the process noise and measurement noise. Ideally, $\hat{x}(k)$ will be equal to $x(k)$ (true state) from Figure \ref{fig:control_architecture}, but in practice, they converge to the true values, but there will be some estimation error. The Kalman filter equations are given by:
\begin{equation}
\begin{aligned}
\hat{x}[k+1] &= A \hat{x}[k] + B u[k] + L (y[k] - \hat{y}[k]) \\
\hat{y}[k] &= C \hat{x}[k] + D u[k]
\end{aligned}
\end{equation}
where $L$ is the Kalman gain matrix, which is computed by solving the discrete-time algebraic Riccati equation. The Kalman gain $L$ determines how much weight is given to the measurement error in updating the state estimate $\hat{x}[k]$. The Kalman filter provides an estimate of the system states $\hat{x}[k]$, which can be used for feedback control in the LQR and LQI controllers.

\newpage
\subsection{State-feedback controller design}
\subsubsection{LQR control}
First, a LQR controller is designed based on the identified state-space model. The LQR control law is given by 
\begin{equation}
u[k] = -K x[k]
\end{equation}
where $K$ is the gain matrix obtained by solving the discrete-time algebraic Riccati equation. The Ricatti equation is solved using the \texttt{dlqr} function from the \texttt{python-control} package, which computes the optimal gain matrix $K$ that minimizes the cost function:
\begin{equation}
J = \sum_{k=0}^{\infty} (x[k]^T Q x[k] + u[k]^T R u[k])
\end{equation}
where $Q$ and $R$ are weighting matrices that penalize deviations from the desired state and control effort, respectively. These can be chosen based on a slider tool and changes the behavior from conservative to aggressive. After solving, the optimal control law is given by:
\begin{equation}
u[k] = -K x[k].
\end{equation}
However, the LQR controller does not guarantee zero steady-state error for tracking a reference signal. To address this, an error integrator is added to the system, in the form of 
\begin{equation}
z[k+1] = z[k] + T_s\left(r[k] - y[k]\right)
\end{equation}
where $T_s$ is the sampling time, $r[k]$ is the reference signal, and $y[k]$ is the output. The integrator state $z[k]$ accumulates the error between the reference and the output, allowing the controller to adjust the control input to eliminate steady-state error, resulting in an LQI controller.

\subsubsection{LQI control}
The LQI controller augments the state-space model with an integrator on the output error. The augmented state vector $\tilde{x}[k]$ is defined as:
\begin{equation}
\tilde{x}[k] = \begin{bmatrix} x[k] \\ z[k] \end{bmatrix}
\end{equation}
where $z[k]$ is the integrator state, which accumulates the error between the reference signal and the output. The augmented system dynamics are given by:
\begin{equation}
\begin{aligned}
\tilde{x}[k+1] &= \tilde{A} \tilde{x}[k] + \tilde{B} u[k] + \tilde{E} r[k] \\
y[k] &= \tilde{C} \tilde{x}[k] + \tilde{D} u[k]
\end{aligned}
\end{equation}
where:
\begin{equation}
\tilde{A} = \begin{bmatrix} A & 0 \\ -C \cdot T_s & I \end{bmatrix}, \quad
\tilde{B} = \begin{bmatrix} B \\ -D \cdot T_s \end{bmatrix}, \quad
\tilde{C} = \begin{bmatrix} C & 0 \end{bmatrix}, \quad
\tilde{D} = D, \quad
\tilde{E} = \begin{bmatrix} 0 \\ T_s \end{bmatrix}
\end{equation}
The control law for the LQI controller is given by:
\begin{equation}
u[k] = -\tilde{K} \tilde{x}[k].
\end{equation}
The LQI controller is designed by defining again a cost function, but now for the augmented system:
\begin{equation}
J = \sum_{k=0}^{\infty} (\tilde{x}[k]^T \tilde{Q}_{LQI} \tilde{x}[k] + u[k]^T \tilde{R}_{LQI} u[k])
\end{equation}
where 
\begin{equation}
\label{eq:weight}
\tilde{Q}_{LQI} = \begin{bmatrix} Q & 0 \\ 0 & speed \end{bmatrix}, \quad
\tilde{R}_{LQI} = R.
\end{equation}
The parameter $speed$ determines the relative importance of eliminating tracking error. A larger value increases the emphasis on reference tracking and typically reduces steady-state error more rapidly, while potentially increasing control effort. 

The optimal gain matrix $\tilde{K}$ is obtained by solving the discrete-time Riccati equation for the augmented system. The resulting controller combines optimal state-feedback regulation with integral action, providing both good transient performance and zero steady-state tracking error.

\paragraph{LQI antiwindup}
To prevent integrator windup, an anti-windup scheme is implemented. When the control input $u[k]$ exceeds the actuator limits, the integrator state is not updated, preventing the integrator from accumulating error that cannot be corrected due to actuator saturation.

\paragraph{Kalman observer}
It is important to note that the LQI controller uses the estimated states $\hat{x}[k]$ from the Kalman observer instead of the true states $x[k]$. The control law is therefore modified to:
\begin{equation}
u[k] = -\tilde{K} \begin{bmatrix} \hat{x}[k] \\ z[k] \end{bmatrix}.
\end{equation}

\subsection{Setpoint filtering}
\label{sec:setpoint_filter}
Saturation occurs when the control input exceeds the actuator limits, which can lead to integrator windup. This happens not only when the control input is below 0\% valve opening or above 100\% valve opening, but also when the valve is adjusted further while the flow is choked. The latter can occur when the reference pressure is changed too quickly, causing the controller to demand a control action that exceeds the physical capabilities of the valve. This can result in a temporary loss of control. 

To mitigate this, a setpoint filter option is implemented to smooth the reference signal before it is fed into the controller. The setpoint filter is designed as a first-order low-pass filter with a time constant $\tau$, which is based on the identified system dynamics. During the identification process, the time constants for both inflow and outflow segments are estimated as functions of pressure ($\tau_{in}(p)$ and $\tau_{out}(p)$). These time constants are then used to define the setpoint filter, ensuring that the reference signal changes at a rate that the system can physically respond to without causing saturation or integrator windup. This strategy helps usuring stability and performance and forces the controller to operate within the physical limits of the system.

\subsection{Inner versus outer loop}
The strategy as described can be applied to both the inner and outer control loops of the EQ-DA system. The inner loop typically controls the fast reference pressure while the outer loop controls a slower variable, such as forward pressure or flow. The inner loop is designed to stabilize the system and reject disturbances quickly, while the outer loop ensures accurate tracking of the desired setpoint over a longer time horizon. The design of both loops follows the same principles of state-space modeling, observer design, and LQI controller synthesis.

Eventually, systems identifcation yields a single state-space model that consists of states describing the inner loop dynamics, and states describing the outer loop dynamics. Any interaction can also be captured in the state-space model.

\section{Results: internal loop}
An EQ-DA was connected to an upstream pressure of 25 bar. A 100 micron flow restrictor was placed on the reference pressure side, so the inlet valve is the primary control element and controller against a constant leak. Main objective is to design single-valve controller based on a LQI controller.

\subsection{Open-loop data collection}
An open-loop identification experiment was conducted to obtain a state-space model of the internal EQ-DA dynamics. The experiment, sampled at
$T_s = 5$~ms, consisted of four consecutive phases:
\begin{enumerate}
    \item \textbf{Inflow (2~s):} the inlet valve was fully opened. The resulting pressure rise is used later to estimate the inflow time constant.
    \item \textbf{Open-loop PRBS excitation (10~s):} a PRBS signal with an amplitude of $\pm 5\%$ was applied around a manually determined operating point of
          52.5\% valve opening. This operating point was chosen such that the average output (reference pressure) was approximately 10~bar.
    \item \textbf{Pressure build-up (2~s):} the inlet valve was fully opened again to bring the system to maximum pressure.
    \item \textbf{Outflow (8~s):} the outlet valve was opened. The resulting pressure decay is used to estimate the outflow time constant.
\end{enumerate}
The \texttt{n4sid} method was applied to the input-output data from the PRBS phase to estimate the state-space matrices $A$, $B$, $C$, and $D$, with the input expressed relative to the operating point. Based on the singular values, a fourth-order model was selected. The identified model captures the essential dynamics of the system and forms the basis for the observer and controller design in the following sections.

\subsection{Maximum inflow and outflow time constants}
The inflow and outflow time constants are estimated from the pressure rise and decay segments of the open-loop identification experiment. A single fit of a first-order exponential function to the entire inflow or outflow did not provide a good fit, so the segments were divided into 1~bar pressure bands, and a first-order exponential function was fitted to each band. The resulting time constants for each band are shown in Figure~\ref{fig:time_constants}. The maximum inflow time constant is slight lower than the maximum outflow time constant. Besides that, the time constant increases when the setpoint pressure is reached. Therefore, setpoint changes close to the maximum upstream pressure, or close to zero should be filtered more than setpoint changes in the middle of the operating range.

The found time constants are used to define the setpoint filter for the LQI controller, ensuring that the reference signal changes at a rate that the system can physically respond to without causing saturation or integrator windup.

\subsection{Setpoint filtering}
Figure \ref{fig:setpoint_filtering} shows setpoints alternating between 1 and 2 bar, with a speed factor of 500. A decreasing setpoint leads to choked flow, where the maximum valve flow is reached. The controller continues to integrate, causing the valve to close while the maximum pressure decay is reached. This causes integrator windup and a temporary loss of control, resulting in an undershoot. An alternative is a setpoint filter, as discussed in Section~\ref{sec:setpoint_filter}, which smooths the reference signal before it reaches the controller. The first-order low-pass filter uses a time constant based on the identified system dynamics, preventing setpoint changes that exceed the system's capabilities and cause saturation. It is disabled when the pressure reaches $\pm10\%$ of the setpoint.
The filter works well for decreasing setpoints but less well for increasing setpoints. Although it largely prevents over- and undershoot, it does not guarantee optimal performance. Its tuning balances responsiveness and stability within the physical limits of the system.

\section{Summary for implementation on EQ-DA hardware}
With help from AI. :) The procedure is split into two parts. Algorithm~\ref{alg:offline} covers the steps performed once, prior to implementation (data collection, identification
and controller synthesis). This is the offline procedure and can be performed in the GUI. Algorithm~\ref{alg:online} is the real-time routine executed on the EQ-DA every sample period $T_s$ and implements the LQI control law with anti-windup. The real-time routine can be implemented in the EQ-DA firmware.
\renewcommand{\algorithmicrequire}{\textbf{Input:}}
\renewcommand{\algorithmicensure}{\textbf{Output:}}

\begin{algorithm}[ht]
\caption{Prior to implementation (offline) using open-loop identification}\label{alg:offline}
\begin{algorithmic}[1]
\Require $T_s = 5$ ms, $u_{\max} = 20\,000$, PRBS base found by experimentation: e.g., $u_0 = 10\,500$,
         amplitude $1000$, switch probability $0.1$, model order $n = 4$,
         weights $Q, R$, speed factor, noise covariances $Q_n, R_n$
\Ensure $A, B, C, D, L, K_x, K_i$, and $\tau_{\text{in}}(p)$, $\tau_{\text{out}}(p)$
\Procedure{DesignLQIOpenLoop}{}
  \Statex \textit{Data collection (open-loop, sampled at $T_s$)}
  \State $u \gets u_{\max}$ for 2 s \Comment{inflow segment}
  \State $u \gets u_0 \pm 1000$ (PRBS) for 10 s \Comment{identification segment}
  \State $u \gets u_{\max}$ for 2 s \Comment{build up pressure}
  \State $u \gets 0$ for 8 s \Comment{outflow segment}
  \Statex \textit{System identification (PRBS segment only)}
  \State $\delta u[k] \gets u[k] - u_0$
  \State Run \texttt{n4sid} on $(\delta u, y)$ with 20 block rows
%   \State Choose $n$ from the singular values; $\{A,B,C,D\} \gets$ model of order $n$
  \Statex \textit{Setpoint filter time constants}
  \State Fit $p(t) = p_\infty + (p_0 - p_\infty)\,e^{-t/\tau}$ on the inflow
         and outflow segments
  \For{each 1 bar pressure band of each segment}
    \State Fit $\tau$ with $p_\infty$ fixed from the full-segment fit
  \EndFor
  \State $\tau_{\text{in}}(p), \tau_{\text{out}}(p) \gets$ linear interpolation
         between band values
  \Statex \textit{Kalman observer}
  \State $L \gets \texttt{dlqe}(A, I, C, Q_n, R_n)$, \quad $Q_n = R_n = 10^{-3}$
  \Statex \textit{LQI controller}
  \State $\tilde{A} \gets \begin{bmatrix} A & 0 \\ -C T_s & 1 \end{bmatrix}$,
         \quad $\tilde{B} \gets \begin{bmatrix} B \\ -D T_s \end{bmatrix}$
    \State $\tilde{Q} \gets \operatorname{diag}(10^{3} I_n,\; 10^{3}\cdot\text{speed})$, \Comment{Speed determines the aggressiveness/robustness trade-off}
         \quad $R \gets 10^{-3}$
  \State $\tilde{K} \gets \texttt{dlqr}(\tilde{A}, \tilde{B}, \tilde{Q}, R)$;
         \quad partition $\tilde{K} = [K_x \;\, K_i]$
  \State Store $\{A, B, C, D, K_x, K_i, L, T_s\}$
  \State Upload parameters onto EQ-DA
\EndProcedure
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[ht]
\caption{Real-time LQI control on the EQ-DA (every $T_s$)}\label{alg:online}
\begin{algorithmic}[1]
\Require Stored controller parameters $\{A, B, C, D, K_x, K_i, L, T_s\}$, $\tau_{\text{in}}(p)$, $\tau_{\text{out}}(p)$,
         integrator limit $z_{\max} = 50$
\Procedure{LQIControl}{}
  \State $\hat{x} \gets 0$, \quad $z \gets 0$, \quad $u \gets 0$
  \For{40 samples} \Comment{observer warm-up, 200 ms}
    \State $y \gets$ measured pressure
    \State $\hat{x}^- \gets A\hat{x} + Bu$; \quad
           $\hat{x} \gets \hat{x}^- + L\,(y - C\hat{x}^- - Du)$
  \EndFor
  \Loop
    \State $(r, y) \gets$ setpoint and measured pressure
    \Statex \hspace{\algorithmicindent}\textit{Setpoint filter}
    \If{$r - y > 0.1\,y$} \Comment{large step up}
      \State $\alpha \gets T_s / (\tau_{\text{in}}(y) + T_s)$; \quad
             $r_f \gets r_f + \alpha\,(r - r_f)$
    \ElsIf{$r - y < -0.1\,y$} \Comment{large step down}
      \State $\alpha \gets T_s / (\tau_{\text{out}}(y) + T_s)$; \quad
             $r_f \gets r_f + \alpha\,(r - r_f)$
    \Else
      \State $r_f \gets r$
    \EndIf
    \Statex \hspace{\algorithmicindent}\textit{Kalman observer}
    \State $\hat{x}^- \gets A\hat{x} + Bu$ \Comment{$u$ from previous sample}
    \State $\hat{x} \gets \hat{x}^- + L\,(y - C\hat{x}^- - Du)$
    \Statex \hspace{\algorithmicindent}\textit{Integral action with anti-windup}
    \State $e \gets r_f - y$
    \State $z_c \gets \min(\max(z + T_s e,\, -z_{\max}),\, z_{\max})$
    \State $v \gets -K_x\hat{x} - K_i z$
    \If{$0 \le v \le u_{\max}$ \textbf{or} $(v > u_{\max} \wedge e < 0)$
        \textbf{or} $(v < 0 \wedge e > 0)$}
      \State $z \gets z_c$ \Comment{integrate unless it deepens saturation}
    \EndIf
    \Statex \hspace{\algorithmicindent}\textit{Control output}
    \State $u \gets \min(\max(-K_x\hat{x} - K_i z,\, 0),\, u_{\max})$
    \State Write $u$ to the valve; wait until the next sample
  \EndLoop
  \State On exit: set valves to the safe state
\EndProcedure
\end{algorithmic}
\end{algorithm}
