\section*{Introduction}
This report presents the development of a \textit{Linear Quadratic Integral} (LQI) controller for the EQ-DA system. The controller is based on a state-space model identified from experimentally acquired closed- or open-loop data. Because the EQ-DA does not hold a fixed operating point without feedback (its pressure drifts slowly and is very sensitive to the valve opening), system identification can be performed under \textit{Proportional-Integral-Derivative} (PID) stabilization using \textit{pseudo-random binary sequence} (PRBS) excitation, or by applying an open-loop PRBS signal around a manually found operating point.

The identified model is subsequently used to design a Kalman state observer and an LQI controller. The resulting control architecture combines optimal state-feedback control with integral action to achieve accurate setpoint tracking without steady-state error. The LQI controller is intended to be tuned with a single slider that sets the trade-off between control effort and tracking performance. The report also includes experimental results demonstrating the effectiveness of the proposed control strategy.

The proposed methodology can be applied to both the inner and outer control loops of the EQ-DA system. The report describes the system identification procedure, observer design methodology, controller synthesis, and experimental results.

\section{Methods}
This section describes the proposed model-based control design procedure. As illustrated in Figure~\ref{fig:workflow}, the method consists of four sequential steps: (1) closed-loop data collection using PID stabilization and PRBS excitation, or open-loop data collection with PRBS excitation; (2) state-space model identification using the \textit{numerical algorithms for subspace state space system identification} (N4SID) algorithm; (3) Kalman observer design for state estimation; and (4) \textit{Linear Quadratic Regulator} (LQR) and \textit{Linear Quadratic Integral} (LQI) controller synthesis based on the identified model. Each step is described in detail in the following sections.

\subsection{Control strategy}
Figure~\ref{fig:control_architecture} illustrates the proposed control architecture. The controller consists of three components: a Kalman state observer, state-feedback control, and integral action. The Kalman observer estimates the system states from the measured output and the applied control input. These estimated states are fed back through the gain matrix $K_x$ to generate the control action. The state-feedback gain is computed using LQR theory, which minimizes a cost function that balances state regulation and control effort. To eliminate steady-state tracking errors, an integrator is added on the output error. The resulting augmented controller is referred to as an LQI controller. By including the integral state in the control law, the system can accurately track reference signals while keeping the advantages of optimal state-feedback control.

\subsection{State-space model}
A key step in model-based control design is a state-space representation of the EQ-DA dynamics, also called the mathematical model. The state-space model provides a compact mathematical description of the system in terms of internal states, control inputs, and measured outputs:
\begin{equation}
\begin{aligned}
x[k+1] &= Ax[k] + Bu[k] \\
y[k] &= Cx[k] + Du[k]
\end{aligned}
\label{eq:ss}
\end{equation}
where:
\begin{itemize}
    \item $k$ is the discrete time index,
    \item $x[k] \in \mathbb{R}^{n}$ is the state vector; the number of states $n$ is the order of the system,
    \item $u[k] \in \mathbb{R}^{m}$ is the control input, $m$ is the number of inputs of the system,
    \item $y[k] \in \mathbb{R}^{p}$ is the output, $p$ is the number of outputs of the system,
    \item $A \in \mathbb{R}^{n \times n}$, $B \in \mathbb{R}^{n \times m}$, $C \in \mathbb{R}^{p \times n}$, and $D \in \mathbb{R}^{p \times m}$ are the system matrices.
\end{itemize}
A dynamically complex system results in a higher-order state-space model (higher $n$), while a simpler system results in a lower-order model (lower $n$). The state-space model can be used to design controllers, such as LQR and LQI controllers, to achieve the desired performance and stability. \textit{Model predictive control} (MPC) can also be designed based on the state-space model, allowing for optimal control of the system over a finite time horizon.

\subsection{State-space model identification}
\subsubsection{Closed-loop identification}
Because the EQ-DA does not hold a fixed operating point without feedback, closed-loop identification can be used to obtain its state-space model. Figure~\ref{fig:closedloop_identification} shows a roughly tuned PID controller that keeps the system near its operating point during identification, while a PRBS excites it across a range of frequencies. The PRBS is generated using the \texttt{prbs} function from the \texttt{python-control} package and applied as the reference input. The resulting input-output data is then used with the \texttt{n4sid} method to estimate the state-space matrices $A$, $B$, $C$, and $D$. Importantly, the PID controller output is the actual EQ-DA input and is therefore used as the input signal for the \texttt{n4sid} identification algorithm. The identified model can subsequently be used for controller design and analysis. However, this method requires a roughly tuned PID controller, which may not always be feasible or desirable. In such cases, open-loop identification can be performed around a manually found operating point.

\subsubsection{Open-loop identification}
As an alternative to closed-loop identification, open-loop identification can be performed by applying a PRBS signal around a manually found operating point. This approach requires some tuning of the PRBS amplitude and switching rate so that the pressure stays near the operating point during the experiment. The input-output data collected from the open-loop experiment is then used with the \texttt{n4sid} method to estimate the state-space matrices. Open-loop identification avoids the correlation between input and noise that feedback introduces, and therefore gives a more direct estimate of the system dynamics, but it is harder to carry out because the pressure drifts away from the operating point without feedback.

\subsubsection{State interpretation}
When identification starts from a physical (white-box) model, the identified states correspond to physical quantities such as pressures or flows. For the EQ-DA no such model is used: \texttt{n4sid} produces a black-box model whose states are an arbitrary linear combination of the underlying physical quantities and cannot be interpreted directly. Only the input-output behaviour is meaningful. A consequence is that state weights in the LQR cost (Section~\ref{sec:lqr}) have no direct physical meaning, which is one reason to weight the output instead (see the remark after Equation~\eqref{eq:weight}).

\newpage
\subsection{Kalman observer}
After finding the state-space model, a state observer can be designed to estimate the system states from the measured output and the applied control input. The observer provides an estimate of the internal states, which are not directly measurable, so that feedback control can be based on these estimated states. The observer also filters measurement noise.

Different types of state observers can be designed. In this report, a Kalman observer is designed based on the identified state-space model. The Kalman filter is an optimal state estimator that minimizes the estimation error covariance, given the process noise and measurement noise covariances. The estimate $\hat{x}(k)$ converges towards the true state $x(k)$ of Figure~\ref{fig:control_architecture}, but a residual estimation error remains because of noise and model error. In predictor form, the Kalman filter equations are:
\begin{equation}
\begin{aligned}
\hat{x}[k+1] &= A \hat{x}[k] + B u[k] + L (y[k] - \hat{y}[k]) \\
\hat{y}[k] &= C \hat{x}[k] + D u[k]
\end{aligned}
\label{eq:kalman}
\end{equation}
where $L$ is the Kalman gain matrix, computed by solving the discrete-time algebraic Riccati equation (function \texttt{dlqe} in \texttt{python-control}, which returns the gain for this predictor form). The Kalman gain $L$ determines how much weight is given to the output prediction error when updating the state estimate $\hat{x}[k]$. The estimate $\hat{x}[k]$ is used for feedback in the LQR and LQI controllers.

\newpage
\subsection{State-feedback controller design}
\subsubsection{LQR control}
\label{sec:lqr}
First, an LQR controller is designed based on the identified state-space model. The LQR control law is
\begin{equation}
u[k] = -K x[k]
\label{eq:lqr}
\end{equation}
where $K$ is the gain matrix obtained by solving the discrete-time algebraic Riccati equation. The Riccati equation is solved using the \texttt{dlqr} function from the \texttt{python-control} package, which computes the gain $K$ that minimizes the cost function
\begin{equation}
J = \sum_{k=0}^{\infty} \left(x[k]^T Q x[k] + u[k]^T R u[k]\right)
\end{equation}
where $Q$ and $R$ are weighting matrices that penalize deviations of the state and control effort, respectively. Their ratio sets the behaviour from conservative to aggressive and can be adjusted with a slider.

However, the LQR controller does not guarantee zero steady-state error when tracking a reference signal. To address this, an error integrator is added:
\begin{equation}
z[k+1] = z[k] + T_s\left(r[k] - y[k]\right)
\label{eq:integrator}
\end{equation}
where $T_s$ is the sampling time, $r[k]$ is the reference signal, and $y[k]$ is the output. The integrator state $z[k]$ accumulates the error between the reference and the output, so that the controller removes any steady-state error. This results in an LQI controller.

\subsubsection{LQI control}
The LQI controller augments the state-space model with the integrator of Equation~\eqref{eq:integrator}. The augmented state vector $\tilde{x}[k]$ is defined as:
\begin{equation}
\tilde{x}[k] = \begin{bmatrix} x[k] \\ z[k] \end{bmatrix}.
\end{equation}
The augmented system dynamics are given by:
\begin{equation}
\begin{aligned}
\tilde{x}[k+1] &= \tilde{A} \tilde{x}[k] + \tilde{B} u[k] + \tilde{E} r[k] \\
y[k] &= \tilde{C} \tilde{x}[k] + \tilde{D} u[k]
\end{aligned}
\end{equation}
where, for a single output,
\begin{equation}
\tilde{A} = \begin{bmatrix} A & 0 \\ -C \cdot T_s & 1 \end{bmatrix}, \quad
\tilde{B} = \begin{bmatrix} B \\ -D \cdot T_s \end{bmatrix}, \quad
\tilde{C} = \begin{bmatrix} C & 0 \end{bmatrix}, \quad
\tilde{D} = D, \quad
\tilde{E} = \begin{bmatrix} 0 \\ T_s \end{bmatrix}.
\label{eq:augmented}
\end{equation}
The control law for the LQI controller is:
\begin{equation}
u[k] = -\tilde{K} \tilde{x}[k] = -K_x x[k] - K_i z[k].
\end{equation}
The gain $\tilde{K}$ minimizes a cost function for the augmented system:
\begin{equation}
J = \sum_{k=0}^{\infty} \left(\tilde{x}[k]^T \tilde{Q}_{LQI} \tilde{x}[k] + u[k]^T \tilde{R}_{LQI} u[k]\right)
\end{equation}
where
\begin{equation}
\tilde{Q}_{LQI} = \begin{bmatrix} Q & 0 \\ 0 & q_z \end{bmatrix}, \quad
\tilde{R}_{LQI} = R, \quad q_z = 10^3 \cdot \text{speed}.
\label{eq:weight}
\end{equation}
The parameter $\text{speed}$ determines the relative importance of eliminating the tracking error. A larger value increases the emphasis on reference tracking and removes the error faster, at the cost of more control effort and less robustness. In the implementation $Q = 10^3 I_n$ and $R = 10^{-3}$ (Algorithm~\ref{alg:offline}). Because the states are not physical (Section~1.3.3), an alternative is $Q = q\,C^T C$, which weights the predicted pressure instead of the abstract states and makes the slider setting easier to interpret.

$\tilde{K}$ is obtained by solving the discrete-time algebraic Riccati equation for the augmented system and partitioned as $\tilde{K} = [K_x \;\, K_i]$. The resulting controller combines optimal state-feedback regulation with integral action, giving good transient performance and zero steady-state tracking error.

\paragraph{LQI anti-windup}
To prevent integrator windup, conditional integration is used. When the unsaturated control signal is outside the actuator range $[0, u_{\max}]$, the integrator is only updated if this moves the control signal back towards the range; otherwise it is frozen. In addition, the integrator state is clamped to $\pm z_{\max}$. See Algorithm~\ref{alg:online} for the exact rule. Note that this scheme only acts on valve-position limits, not on choked flow (Section~\ref{sec:setpoint_filter}).

\paragraph{Kalman observer}
The LQI controller uses the estimated states $\hat{x}[k]$ from the Kalman observer instead of the true states $x[k]$. The control law is therefore:
\begin{equation}
u[k] = -\tilde{K} \begin{bmatrix} \hat{x}[k] \\ z[k] \end{bmatrix}.
\end{equation}

\subsection{Setpoint filtering}
\label{sec:setpoint_filter}
Saturation occurs when the controller asks for more than the actuator can deliver, which can lead to integrator windup. This happens not only when the requested valve opening is below 0\% or above 100\%, but also when the valve is moved further while the flow is already choked. The latter occurs when the reference pressure is changed faster than the system can follow, so the controller demands an action beyond the physical capabilities of the valve. This can result in a temporary loss of control.

To mitigate this, an optional setpoint filter smooths the reference signal before it is fed to the controller. The setpoint filter is a first-order low-pass filter with a time constant $\tau$ based on the identified system dynamics. During the identification experiment, the time constants of the inflow and outflow segments are estimated as functions of pressure ($\tau_{in}(p)$ and $\tau_{out}(p)$). These time constants set the setpoint filter, so that the reference signal changes at a rate the system can physically follow without saturation or integrator windup. This keeps the controller within the physical limits of the system and improves stability and performance.

\subsection{Inner versus outer loop}
The strategy described above can be applied to both the inner and outer control loops of the EQ-DA system. The inner loop typically controls the fast reference pressure, while the outer loop controls a slower variable, such as forward pressure or flow. The inner loop is designed to stabilize the system and reject disturbances quickly, while the outer loop ensures accurate tracking of the desired setpoint over a longer time horizon. The design of both loops follows the same principles of state-space modelling, observer design, and LQI controller synthesis.

Eventually, system identification yields a single state-space model with states describing the inner-loop dynamics and states describing the outer-loop dynamics. Any interaction between the loops is then captured in the same model.

\subsection{Open-loop data collection}
An open-loop identification experiment was conducted to obtain a state-space model of the internal EQ-DA dynamics. The experiment, sampled at $T_s = 5$~ms, consisted of four consecutive phases:
\begin{enumerate}
    \item \textbf{Inflow (2~s):} the inlet valve was fully opened. The resulting pressure rise is used to estimate the inflow time constant.
    \item \textbf{Open-loop PRBS excitation (10~s):} a PRBS signal with an amplitude of $\pm 5\%$ was applied around a manually determined operating point of 52.5\% valve opening. The resulting average reference pressure was approximately 13~bar. % CHECK: the text previously said 10 bar; Figure 5 shows about 12-14 bar.
    \item \textbf{Pressure build-up (2~s):} the inlet valve was fully opened again to bring the system to maximum pressure.
    \item \textbf{Outflow (8~s):} the outlet valve was opened. The resulting pressure decay is used to estimate the outflow time constant.
\end{enumerate}
The \texttt{n4sid} method was applied to the input-output data from the PRBS phase to estimate the state-space matrices $A$, $B$, $C$, and $D$, with the input expressed relative to the operating point. Based on the singular values, a fourth-order model was selected. The identified model forms the basis for the observer and controller design in the following sections.

\subsection{Maximum inflow and outflow time constants}
The inflow and outflow time constants are estimated from the pressure rise and decay segments of the open-loop identification experiment. A single first-order exponential fit to the entire inflow or outflow segment did not fit well, so the segments were divided into 1~bar pressure bands and a first-order exponential was fitted to each band. The resulting time constants are shown in Figure~\ref{fig:time_constants}. The inflow time constant is about 0.45--0.65~s over most of the range and rises steeply to about 1.3~s as the pressure approaches the 25~bar supply pressure. The outflow time constant is larger, about 0.85--1.3~s, and increases towards low pressure. In both cases the time constant grows as the pressure approaches the end value of the segment. Setpoint changes close to the upstream pressure, or close to zero, should therefore be filtered more than setpoint changes in the middle of the operating range.

These time constants are used to define the setpoint filter for the LQI controller, so that the reference signal changes at a rate the system can physically follow without saturation or integrator windup.

\subsubsection{Multiple setpoints, speed = 5, 50, 500, 5000}
The setpoint is now stepped between 10 and 12~bar, with speed factors of 5, 50, 500 and 5000 (see Equation~\eqref{eq:weight}). The speed factor sets the aggressiveness of the controller: higher values give a faster response but potentially more overshoot and oscillation. The results are shown in Figure~\ref{fig:multiple_setpoints}. Because the speed factor is a single tuning parameter, it can be set with a slider in the GUI to trade speed against robustness.

The figure shows that a speed factor of about 500 gives fast tracking without significant overshoot. At a speed factor of 5000 the controller is too aggressive: on a decreasing step the integrator keeps integrating and closes the valve while the pressure is already decaying at its maximum rate. This leads to a large undershoot of about 0.9~bar. The effect is strongest on decreasing steps, where the outflow time constant (Figure~\ref{fig:time_constants}) is larger than the inflow time constant.

\subsection{Setpoint filtering}
Figure~\ref{fig:setpoint_filtering} shows setpoints alternating between 1 and 2~bar, with a speed factor of 500. Without filtering, a decreasing setpoint leads to the maximum pressure decay rate being reached. The controller keeps integrating and closes the valve completely while the pressure cannot fall any faster. This causes integrator windup and a temporary loss of control, resulting in an undershoot to about 0.5~bar. With the setpoint filter of Section~\ref{sec:setpoint_filter}, the reference is smoothed with a first-order low-pass filter whose time constant follows the identified dynamics, so the setpoint does not change faster than the system can follow. The filter is bypassed once the pressure is within $\pm10\%$ of the setpoint.

The filter works well for decreasing setpoints but less well for increasing setpoints. It largely prevents over- and undershoot, at the cost of a slower response, and does not guarantee optimal performance. Different filter designs can be explored to obtain better performance, more close to maximal speed without saturation and windup.

    \caption{Effect of setpoint filtering on the closed-loop response of the EQ-DA under LQI control, with the reference alternating between 1 and 2~bar and a speed factor of 500. Without setpoint filtering (blue), the controller winds up during the decreasing setpoint, leading to a temporary loss of control and an undershoot. With filtering (green), the response is smoother and saturation and windup are avoided, at the cost of a slower response.}

\section{Summary for implementation on EQ-DA hardware}
The procedure is split into two parts. Algorithm~\ref{alg:offline} covers the steps performed once, before implementation (data collection, identification and controller synthesis). This offline procedure can be performed in the GUI. Algorithm~\ref{alg:online} is the real-time routine executed on the EQ-DA every sample period $T_s$; it implements the LQI control law with anti-windup and can be implemented in the EQ-DA firmware.
\renewcommand{\algorithmicrequire}{\textbf{Input:}}
\renewcommand{\algorithmicensure}{\textbf{Output:}}

\begin{algorithm}[ht]
\caption{Prior to implementation (offline) using open-loop identification}\label{alg:offline}
\begin{algorithmic}[1]
\Require $T_s = 5$ ms, $u_{\max} = 20\,000$, PRBS base found by experimentation: e.g., $u_0 = 10\,500$,
         amplitude $1000$, switch probability $0.1$, model order $n = 4$,
         weights $Q, R$, speed factor, noise covariances $Q_n, R_n$
\Ensure $A, B, C, D, L, K_x, K_i$, and $\tau_{\text{in}}(p)$, $\tau_{\text{out}}(p)$
\Procedure{DesignLQIOpenLoop}{}
  \Statex \textit{Data collection (open-loop, sampled at $T_s$)}
  \State $u \gets u_{\max}$ for 2 s \Comment{inflow segment}
  \State $u \gets u_0 \pm 1000$ (PRBS) for 10 s \Comment{identification segment}
  \State $u \gets u_{\max}$ for 2 s \Comment{build up pressure}
  \State $u \gets 0$ for 8 s \Comment{outflow segment}
  \Statex \textit{System identification (PRBS segment only)}
  \State $\delta u[k] \gets u[k] - u_0$
  \State Run \texttt{n4sid} on $(\delta u, y)$ with 20 block rows
  \Statex \textit{Setpoint filter time constants}
  \State Fit $p(t) = p_\infty + (p_0 - p_\infty)\,e^{-t/\tau}$ on the inflow
         and outflow segments
  \For{each 1 bar pressure band of each segment}
    \State Fit $\tau$ with $p_\infty$ fixed from the full-segment fit
  \EndFor
  \State $\tau_{\text{in}}(p), \tau_{\text{out}}(p) \gets$ linear interpolation
         between band values
  \Statex \textit{Kalman observer}
  \State $L \gets \texttt{dlqe}(A, I, C, Q_n, R_n)$, \quad $Q_n = R_n = 10^{-3}$
         \Comment{predictor-form gain}
  \Statex \textit{LQI controller}
  \State $\tilde{A} \gets \begin{bmatrix} A & 0 \\ -C T_s & 1 \end{bmatrix}$,
         \quad $\tilde{B} \gets \begin{bmatrix} B \\ -D T_s \end{bmatrix}$
  \State $\tilde{Q} \gets \operatorname{diag}(10^{3} I_n,\; 10^{3}\cdot\text{speed})$, \quad $R \gets 10^{-3}$
         \Comment{speed sets the aggressiveness}
  \State $\tilde{K} \gets \texttt{dlqr}(\tilde{A}, \tilde{B}, \tilde{Q}, R)$;
         \quad partition $\tilde{K} = [K_x \;\, K_i]$
  \State Store $\{A, B, C, D, K_x, K_i, L, T_s\}$
  \State Upload parameters onto EQ-DA
\EndProcedure
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[ht]
\caption{Real-time LQI control on the EQ-DA (every $T_s$)}\label{alg:online}
\begin{algorithmic}[1]
\Require Stored controller parameters $\{A, B, C, D, K_x, K_i, L, T_s\}$, $\tau_{\text{in}}(p)$, $\tau_{\text{out}}(p)$,
         integrator limit $z_{\max} = 50$; assumes $-K_i > 0$ (more integral gives more valve opening)
\Procedure{LQIControl}{}
  \State $\hat{x} \gets 0$, \quad $z \gets 0$, \quad $u \gets 0$
  \For{40 samples} \Comment{observer warm-up, 200 ms}
    \State $y \gets$ measured pressure
    \State $\hat{x} \gets A\hat{x} + Bu + L\,(y - C\hat{x} - Du)$
  \EndFor
  \State $r_f \gets y$ \Comment{initialise setpoint filter}
  \Loop
    \State $(r, y) \gets$ setpoint and measured pressure
    \Statex \hspace{\algorithmicindent}\textit{Setpoint filter}
    \If{$r - y > 0.1\,y$} \Comment{large step up}
      \State $\alpha \gets T_s / (\tau_{\text{in}}(y) + T_s)$; \quad
             $r_f \gets r_f + \alpha\,(r - r_f)$
    \ElsIf{$r - y < -0.1\,y$} \Comment{large step down}
      \State $\alpha \gets T_s / (\tau_{\text{out}}(y) + T_s)$; \quad
             $r_f \gets r_f + \alpha\,(r - r_f)$
    \Else
      \State $r_f \gets r$
    \EndIf
    \Statex \hspace{\algorithmicindent}\textit{Integral action with anti-windup}
    \State $e \gets r_f - y$
    \State $z_c \gets \min(\max(z + T_s e,\, -z_{\max}),\, z_{\max})$
    \State $v \gets -K_x\hat{x} - K_i z$
    \If{$0 \le v \le u_{\max}$ \textbf{or} $(v > u_{\max} \wedge e < 0)$
        \textbf{or} $(v < 0 \wedge e > 0)$}
      \State $z \gets z_c$ \Comment{integrate unless it deepens saturation}
    \EndIf
    \Statex \hspace{\algorithmicindent}\textit{Control output}
    \State $u \gets \min(\max(-K_x\hat{x} - K_i z,\, 0),\, u_{\max})$
    \State Write $u$ to the valve
    \Statex \hspace{\algorithmicindent}\textit{Kalman observer (predictor form, Equation~\eqref{eq:kalman})}
    \State $\hat{x} \gets A\hat{x} + Bu + L\,(y - C\hat{x} - Du)$ \Comment{estimate for next sample}
    \State Wait until the next sample
  \EndLoop
  \State On exit: set valves to the safe state
\EndProcedure
\end{algorithmic}
\end{algorithm}
